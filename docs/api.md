# API Contract

Base path: `/api`

- `GET /contracts`
- `GET /contracts/{id}`
- `GET /vendors`
- `GET /vendors/{id}`
- `GET /departments`
- `GET /departments/{id}`
- `GET /dashboard/stats`
- `GET /network`
- `GET /risk/{contract_id}`
- `POST /risk/analyze?contract_id={id}`
- `POST /nlp/analyze`
- `POST /blockchain/record`

FastAPI interactive docs are available at `/docs`.
